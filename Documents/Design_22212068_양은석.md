## <a id="intro"></a>1. Introduction

어느 지역에 거주할지 결정할 때 범죄 발생률, 의료시설, 학교, 편의시설 등 다양한 생활 지표를 개별적으로 확인해야 하는 번거로움이 존재한다. 관련 정보가 여러 공공기관에 분산되어 있어 한눈에 비교하기 어렵고, 구/군 단위를 넘어 동 단위의 세밀한 분석은 더욱 어려운 실정이다. 이를 해결하기 위해 본 프로젝트는 공공 API로부터 생활 지표 데이터를 자동 수집·정규화하고, 카카오맵 기반의 웹 인터페이스에서 지역별 종합 점수를 시각적으로 제공하는 주거지 평가 시스템을 개발하였다.

본 문서는 Analysis에 이은 Design 단계의 문서로, class diagram, sequence diagram, state machine diagram을 제시하고 각 diagram에 대한 설명을 기술한다. 추가로 implementation requirements를 기술하여 본 시스템을 구현하기 위한 소프트웨어 및 하드웨어 요구사항을 명시한다. 본 시스템은 Java 기반의 데이터 수집 모듈과 HTML/JavaScript 기반의 프론트엔드로 구성되며, 데이터 수집 자동화에는 GitHub Actions를 활용한다. 수집 범위는 대구광역시를 시작으로 부산광역시·서울특별시로 확장하였다.
